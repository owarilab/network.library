概要

HTTP + WebSocket + ルーム機能をすぐ試せる、http_server_simple 用トップページです。
まずは `wsock.html` で接続/ルーム挙動を確認し、次にミニゲームを複数タブで遊んでみてください。

HTTP API: /api/v1/room/* WebSocket: ws://localhost:4444

通信デモ

WebSocket Room Sample

接続IDの取得、ルーム作成/参加/退出、メッセージ送信を最小構成で確認できます。

開く → /wsock.html

Programming Document

RoomServerManager を使ったフロント実装手順、API、コールバック設計をまとめた技術資料です。

開く → /programing_document.html

ゲームで遊ぶ

Reversi

ルーム同期付きのリバーシ。複数タブで同じルームに入り対戦できます。

開く → /reversi.html

Gomoku

五目並べのマルチプレイヤーサンプル。ルーム参加後に対局を開始します。

開く → /gomoku.html

Dots and Boxes

線を引いて箱を取る対戦ゲーム。ターン制同期のサンプルとして使えます。

開く → /dots_and_boxes.html

Shoot Game

シューティング系のサンプルページ。WebSocket連携の挙動確認にも使えます。

開く → /shoot_game.html

使い方メモ

1. サーバ起動後にこのページを開く
2. 2つ以上のタブで同じゲームページを開く
3. 同じルームIDで join して通信/同期を確認する
4. API検証は /wsock.html の room list / create / join / leave を利用する
