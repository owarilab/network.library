ルーム機能フロント開発ドキュメント

この資料は www/js/room.js の RoomServerManager を使って、 フロントエンドからルーム機能を扱うための実装手順をまとめたものです。

対象サンプル: wsock.html API: /api/v1/room/* WebSocket: ws://localhost:4444
目次: 1. 全体像 2. 初期化 3. HTTP API 4. コールバック 5. 実装例 6. 運用Tips

1. 全体像

  • 接続直後に UUID を送信し、サーバからの echo で selfConnectionId を確定します。
  • ルーム操作（create/list/join/leave）は HTTP API を使います。
  • ルーム内メッセージの配信は WebSocket で受け取ります。
  • ユーザーロジックはコールバックに集約し、画面側コードをシンプルに保てます。

WebSocket受信JSONの基本形: { id, type, message }

2. 初期化と接続

2.1 スクリプト読み込み

<script src="/js/room.js"></script>

2.2 インスタンス生成

const manager = new RoomServerManager({
  httpBase: window.location.origin,
  wsBase: (window.location.protocol === 'https:' ? 'wss://' : 'ws://') + window.location.host,
  callbacks: {
    onSelfConnectionId: ({ connectionId }) => {
      console.log('self connection id:', connectionId);
    },
    onJoin: ({ connectionId }) => {
      console.log('joined user:', connectionId);
    },
    onLeave: ({ connectionId }) => {
      console.log('left user:', connectionId);
    },
    onHttpError: ({ error }) => {
      console.error('http error:', error);
    }
  }
});

manager.connect();

2.3 主要な状態

  • manager.selfUuid: 自動ハンドシェイク用UUID
  • manager.selfConnectionId: サーバから付与される接続ID
  • manager.currentJoinRoomId: 現在参加中のルームID
  • manager.getState(): 画面表示やデバッグ向け状態取得

3. ルームHTTP APIの使い方

メソッドHTTP説明戻り値
listRooms() GET /api/v1/room/list ルーム一覧を取得 Promise<JSON>
createRoom(name) POST /api/v1/room/create ルーム作成 Promise<JSON>
joinRoom(roomId, connectionId?) POST /api/v1/room/join ルーム参加 Promise<JSON>
leaveRoom(roomId?, connectionId?) POST /api/v1/room/leave ルーム退出 Promise<JSON>

3.1 最小操作例

// ルーム作成
const created = await manager.createRoom('test_room');

// 参加（connectionId省略時は manager.selfConnectionId を使用）
await manager.joinRoom(created.id);

// 一覧
const list = await manager.listRooms();
console.log(list.list);

// 退出
await manager.leaveRoom();

4. コールバック設計

コールバック名用途
onWsOpen / onWsClose / onWsErrorWebSocketライフサイクル監視
onWsRawMessage受信生データのロギング
onSelfConnectionId自身の connection_id 確定タイミング
onMessagetype=message の処理
onJoin / onLeave他ユーザーの入退出通知
onRoomCreate / onRoomList / onRoomJoin / onRoomLeaveHTTP API成功時の処理
onHttpError / onParseError / onCallbackError例外系ハンドリング

4.1 コールバック差し替え

manager.setCallback('onMessage', ({ message, connectionId }) => {
  appendChatLine(connectionId + ': ' + message);
});

manager.setCallbacks({
  onJoin: ({ connectionId }) => appendSystemLine(connectionId + ' joined'),
  onLeave: ({ connectionId }) => appendSystemLine(connectionId + ' left')
});

5. wsock.html準拠の実装例

const manager = new RoomServerManager({
  callbacks: {
    onSelfConnectionId: ({ connectionId }) => {
      selfConId = connectionId;
    },
    onJoin: ({ connectionId }) => {
      if (connectionId !== selfConId) {
        manager.send('hello ' + connectionId + ' my con id is ' + selfConId);
      }
    }
  }
});

manager.connect();

async function createAndJoin(roomName) {
  const created = await manager.createRoom(roomName);
  await manager.joinRoom(created.id);
}

6. 開発・運用Tips

  • 関数名衝突に注意: 要素idと同名関数を作るとブラウザで上書きされる場合があります。
  • 接続ID確定前のjoinを避ける: onSelfConnectionId 後にルーム参加するのが安全です。
  • UI更新はコールバックに集約: 通信層と画面層の責務を分離しやすくなります。
  • HTTPエラーの可視化: onHttpError で status と responseText をログ出力してください。
