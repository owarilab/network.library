# 今後の機能案

最終更新: 2026-04-22

## 方針

このツールは、単なるドット絵エディタとして広げるより、
2Dゲーム向けタイルセット制作ツールとして磨く方が価値が高い。

特に次の3点を強くすると実用品としての完成度が上がる。

1. 作業を壊さない
2. 大量のチップを速く扱える
3. ゲームへそのまま持ち込める

---

## 最優先で入れたい機能

### 1. Undo / Redo

現状でも描画機能はかなり揃っているが、履歴管理がないと実運用では厳しい。
最初に入れるべき機能。

詳細計画:

1. [Undo / Redo 実装計画書](sample/qs_tool_server/UNDO_REDO_PLAN.md)

必要な内容:

1. 1ストローク単位の履歴管理
2. 塗りつぶし、反転、回転、レイヤー操作も履歴化
3. チップコピー、入れ替え、行列追加削除も履歴化
4. 最大履歴数の制限と軽量化

### 2. 選択ツール

矩形選択が入ると、単純な描画ツールから編集ツールになる。

詳細計画:

1. [選択ツール 実装計画書](sample/qs_tool_server/SELECTION_TOOL_PLAN.md)

必要な内容:

1. 矩形選択
2. コピー、切り取り、貼り付け
3. 選択範囲の移動
4. 選択範囲単位の反転、回転
5. 将来的には複数チップ選択にも拡張

### 3. ズームと視認性の改善

既存のズームを実務向けに仕上げると、全体の使い勝手が大きく上がる。

必要な内容:

1. マウス位置中心ズーム
2. 現在の倍率表示
3. 現在座標表示
4. 選択チップ番号表示
5. グリッド色、透明度の設定

### 4. レイヤー操作の完成

レイヤー自体はあるので、管理機能を強化すると制作速度が上がる。

詳細計画:

1. [レイヤー操作 実装計画書](sample/qs_tool_server/LAYER_OPERATIONS_PLAN.md)

必要な内容:

1. レイヤー名変更
2. 不透明度スライダー
3. レイヤーロック
4. レイヤー複製
5. レイヤー結合

### 5. ショートカット強化

操作回数を減らせると、この種のツールは一気に使いやすくなる。

必要な内容:

1. ツール切り替えショートカット
2. 前景色と背景色の入れ替え
3. 一時スポイト、一時手のひら
4. チップ移動のキーボード操作
5. よく使う操作のショートカット一覧表示

## 次に効く機能

### 6. タイルセット向けメタデータ編集

ここが入ると、単なる画像編集ツールではなくゲーム素材ツールになる。

必要な内容:

1. 通過可否の編集UI
2. 地形種別の設定
3. ダメージ床、水、坂などの属性設定
4. タグ、カテゴリ設定
5. チップ単位のメモ
6. 当たり判定プレビュー

### 7. オートタイル支援

量産を支える機能。タイル制作で差が出る部分。

必要な内容:

1. 角、辺、中央のテンプレート生成
2. 接続パターンの自動生成
3. 斜め見下ろしタイル生成の拡張
4. 壁、床、崖、水際などのプリセット
5. 派生チップの一括生成

### 8. マップ配置プレビュー

チップ単体では良く見えても、並べると破綻することがある。
配置プレビューはかなり重要。

必要な内容:

1. 仮マップキャンバス
2. 複数チップを置いた見え方の確認
3. ランダム敷き詰め
4. 通過フラグ可視化
5. 簡易ゲーム風プレビュー

### 9. 一括編集機能

チップ数が増えたときに効く。量産フェーズで重要。

必要な内容:

1. 複数チップ一括選択
2. 一括反転、一括回転
3. パレット置換
4. 特定色の一括差し替え
5. 行列単位のコピー、複製、削除

---

## ゲーム制作ツールとして強くする機能

### 10. 出力形式の強化

現在の保存機能を、実際のゲーム組み込み前提に育てる。

必要な内容:

1. QTS にチップメタデータを正式に含める
2. JSON に通過情報やタグを載せる
3. エンジン向けエクスポータ
4. タイルインデックス一覧出力
5. パレット定義の独立保存

### 11. 検証機能

制作ミスを早く見つけられると、実務でかなり効く。

必要な内容:

1. 未使用チップ検出
2. 透明だけのチップ検出
3. パレット外色検出
4. QTS 化で失われる色の警告
5. タイルサイズ不一致の警告

### 12. アニメーションタイル

将来的には有用だが、現段階では最優先ではない。

必要な内容:

1. フレームパネル
2. タイル単位アニメーション
3. FPS 指定
4. 書き出し
5. プレビュー再生

## 長期的に入れると強い機能

### 13. 図形、補助描画ツール

1. 直線
2. 矩形
3. 楕円
4. ミラー描画
5. タイル境界をまたがない描画制約

### 14. テンプレートとプロジェクト機能

1. 新規作成テンプレート
2. 最近使ったパレット
3. 最近使ったタイルセット
4. 作業セッション復元
5. プロジェクト単位の設定保存

### 15. サーバー連携

HTTPサーバーを持っている構成を活かして、将来的に管理機能へ発展できる。

1. サーバー保存
2. バージョン管理
3. 自動バックアップ
4. 共有レビュー
5. チーム用アセット管理

---

## 推奨開発順

効果が高い順に並べると次の通り。

1. Undo / Redo
2. 矩形選択、コピー、貼り付け
3. ズーム中心改善、座標表示、倍率表示
4. レイヤー名変更、不透明度、ロック
5. ショートカット強化
6. タイルメタデータ編集
7. マップ配置プレビュー
8. 一括編集
9. オートタイル支援
10. 出力形式の拡張

---

## このツールの勝ち筋

このツールは、汎用ペイントソフトではなく、
2Dゲーム向けタイルセット制作ツールとして尖らせるのがよい。

特に重要なのは次の組み合わせ。

1. チップ単位レイヤー
2. 編集可能パレット
3. ゲーム用メタデータ
4. 配置プレビュー
5. ゲーム実装向け保存形式

この方向で進めると、単なる絵を描くツールではなく、
「ゲームに持っていくための制作ツール」として価値が出る。
