# RPG HUD サンプル仕様

## 概要

RPG ゲーム用の HUD（ヘッドアップディスプレイ）表現サンプル。
Rectangle コンポーネントの図形機能と Text コンポーネントを組み合わせた実装例。

## 構成要素

### 1. HP バー
- **背景バー** (`HP_Bar_Background`): 120x20 px の灰色矩形
- **値バー** (`HP_Bar_Value`): 90/100 を表示（幅 90 px の赤色矩形）
- **テキスト** (`HP_Label`): 「HP: 90/100」表示

**使用シェイプ**: Rectangle（矩形）
**色**: 背景は #444444、値は #ff4444

### 2. MP バー
- **背景バー** (`MP_Bar_Background`): 120x20 px の灰色矩形
- **値バー** (`MP_Bar_Value`): 54/60 を表示（幅 108 px の青色矩形）
- **テキスト** (`MP_Label`): 「MP: 54/60」表示

**使用シェイプ**: Rectangle（矩形）
**色**: 背景は #444444、値は #4444ff

### 3. EXP（経験値）バー
- **背景バー** (`EXP_Bar_Background`): 120x12 px の濃灰色矩形
- **値バー** (`EXP_Bar_Value`): 60% 進捗（幅 72 px のオレンジ矩形）

**使用シェイプ**: Rectangle（矩形）
**色**: 背景は #333333、値は #ffaa44

**特徴**: HP/MP バーより小さいサイズで、経験値ゲージを表現

### 4. ステータス表示
- **レベル** (`Level_Indicator`): 「Lv. 25」（黄色テキスト）
- **攻撃力** (`ATK_Stat`): 「ATK:48」（薄赤テキスト）
- **防御力** (`DEF_Stat`): 「DEF:32」（薄青テキスト）
- **状態** (`Status_State`): 「Status: NORMAL」（緑色テキスト）

**特徴**: 複数のステータス値を同時表示可能

### 5. インベントリスロット（3 スロット）

各スロットは背景フレーム + アイテムアイコンで構成

#### スロット 1
- **背景** (`Inventory_Slot_1`): 28x28 px の濃灰色矩形
- **アイコン** (`Inventory_Item_1`): 16x16 px の円形（オレンジ色 #ff6633）
- **表現**: ポーション（円形で表現）

#### スロット 2
- **背景** (`Inventory_Slot_2`): 28x28 px の濃灰色矩形
- **アイコン** (`Inventory_Item_2`): 16x16 px の矩形（青色 #3399ff）
- **表現**: 魔法書（矩形で表現）

#### スロット 3
- **背景** (`Inventory_Slot_3`): 28x28 px の濃灰色矩形
- **アイコン** (`Inventory_Item_3`): 16x16 px の星型（黄色 #ffff33、5 ポイント）
- **表現**: 特殊アイテム（星型で表現）

**特徴**: 各スロットに異なる図形を使用して、異なるアイテムタイプを視覚的に区別

### 6. HUD パネル背景
- **背景** (`HUD_Background_Panel`): 300x150 px の濃灰色半透明矩形
- 全要素をまとめるコンテナとして機能
- 深度 (z = 0) で最背面に配置

## Z オーダー（レイアウト）

```
z = 100  : メインカメラ
z = 3    : HP/MP ラベルテキスト
z = 2    : ステータステキスト、インベントリアイコン、値バー
z = 1    : バー背景、インベントリスロット背景
z = 0    : HUD パネル背景
```

## 使用コンポーネント

### Rectangle コンポーネント使用シーン

| オブジェクト | シェイプ | 用途 |
|------------|--------|------|
| HP_Bar_Background/Value | rectangle | ゲージバー表現 |
| MP_Bar_Background/Value | rectangle | ゲージバー表現 |
| EXP_Bar_Background/Value | rectangle | 経験値バー表現 |
| Inventory_Item_1 | circle | アイテムアイコン（ポーション） |
| Inventory_Item_2 | rectangle | アイテムアイコン（魔法書） |
| Inventory_Item_3 | star | アイテムアイコン（特殊アイテム） |
| HUD_Background_Panel | rectangle | パネル背景フレーム |
| Inventory_Slot_* | rectangle | インベントリスロット背景 |

### Text コンポーネント使用シーン

| オブジェクト | 内容 | 用途 |
|------------|------|------|
| HP_Label | HP: 90/100 | HP 数値表示 |
| MP_Label | MP: 54/60 | MP 数値表示 |
| Level_Indicator | Lv. 25 | プレイヤーレベル表示 |
| ATK_Stat | ATK:48 | 攻撃力表示 |
| DEF_Stat | DEF:32 | 防御力表示 |
| Status_State | Status: NORMAL | ステータス状態表示 |

## 拡張例

このテンプレートを基に以下の拡張が可能：

1. **複数キャラクター HUD**
   - 複数の HP/MP バーを上下配置
   - パーティ全体のステータス表示

2. **攻撃/防御状態表示**
   - バーの色を動的に変更（攻撃態勢時は赤くなるなど）
   - 点滅アニメーション追加

3. **バフ/デバフアイコン**
   - インベントリスロットのような小さい矩形を複数配置
   - 小さい星型や円形で状態異常を表現

4. **ボスバー**
   - より大きな HP バーを画面上部に配置
   - 二段階バー（外側：最大 HP、内側：現在 HP）

5. **ターン制示標**
   - ポリゴン図形で turn order を表現
   - キャラの行動順序を視覚化

## ファイル構成

- `rpg_hud.json`: PlayUnit としての HUD 構成（単体形式）
- `rpg_hud_template.qsproj`: プロジェクトテンプレート（読み込み可能な形式）

## 読み込み方法

1. Editor で「Load Project」
2. `rpg_hud_template.qsproj` を選択
3. PlayUnit が自動読み込みされ、HUD が表示される
